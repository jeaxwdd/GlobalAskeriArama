# 🌍 Global Military & Defense Encyclopedia

![Status](https://img.shields.io/badge/Status-Active-success?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)
![Platform](https://img.shields.io/badge/Platform-Web-orange?style=for-the-badge)

A comprehensive, interactive web encyclopedia built to explore, analyze, and compare military forces, combat aircraft, and weapons systems from around the world.

---

## ✨ Key Features

* **🌐 Global Armed Forces:** Detailed breakdowns of active military personnel, defense budgets, and strategic capabilities by country.
* **✈️ Military Aircraft Database:** Technical specifications, operational history, and performance metrics for fighter jets, bombers, helicopters, and UAVs.
* **🔫 Weapons & Arsenal:** Comprehensive catalog of infantry weapons, armored vehicles, artillery, and missile defense systems.
* **🔍 Fast Search & Filtering:** Instantly filter equipment by country of origin, category, era, or operational status.
* **📱 Responsive Design:** Clean, modern interface optimized for both desktop and mobile browsers.
